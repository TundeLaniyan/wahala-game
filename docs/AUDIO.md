# WAHALA! audio: infrastructure, and what is (not) shipped

State on the unified branch `claude/wahala-unified-pre-gemini`.

## Read this first

The `claude/wahala-lagos-audio` branch produced generated Afrobeats music, synthetic Nigerian Pidgin voices and
generated "Lagos" ambience beds. **The founder rejected all three.** On this branch:

| Part | State |
| --- | --- |
| Generated Afrobeats music (`match_loop`, `menu_loop`, `match_tension`, stings) | **Rejected and removed.** No music file ships; `public/audio/music/manifest.json` lists no tracks, so the music player is silent. |
| Synthetic Pidgin voice packs (Kokoro TTS) | **Rejected and removed.** `public/audio/voices/voices.json` keeps only the line catalogue (ids, categories, text) with `packs: {}`; no line can play until a real recording is listed in `recorded.json`. |
| Generated Lagos ambience beds (`crowd_loop`, `buspark_loop`, `crowd_loop_hype` files) | **Rejected and removed.** `public/audio/slots.json` is empty, so the beds fall back to the runtime-synthesised crowd beds that existed before the audio branch. |
| Generators (`tools/audiogen/`) | **Removed** so the rejected audio cannot be regenerated by accident. They remain in the history of `claude/wahala-lagos-audio`. |
| Infrastructure (volumes, music player, voice/reaction director, manifests, recording slots, lifecycle) | **Kept and tested.** Described below. |

`tests/audio/assets.test.ts` fails if any audio file is added under `public/audio/`, if a manifest lists tracks,
packs, slots or recordings, or if `tools/audiogen/` comes back. Update that test deliberately when real, licensed
audio is added.

Every sound that plays today is synthesised at runtime (`src/audio/recipes`): effects, warnings, engine and
generator loops, the crowd beds and crowd reactions. None of it is a recording; do not describe it as one.

## Layers and volumes

```
music   music.ts loops + stings                   -> musicDuck -> musicBus ----\
sfx     effects                                   -> sfxBus -------------------+
warn    danger warnings (never ducked)            -> warnBus (sfx volume) -----+-> master -> limiter -> out
react   crowd reactions + spoken lines            -> notch -> reactDuck -> crowdBus
amb     ambience beds                             -> notch -> ambDuck  -> crowdBus
```

`src/audio/prefs.ts` holds four independent persistent volumes (localStorage key `wahala.audio.v1`; corrupt or
unavailable storage falls back to the defaults) plus the voices on/off switch:

| Slider | Default | Controls |
| --- | --- | --- |
| Master | 80% | everything |
| Music | 45% | music loops and stings (silent until tracks are added) |
| Ambience & voices | 65% | crowd beds, crowd reactions, spoken lines |
| Effects | 85% | synthesised effects and warnings |

`src/ui/AudioSettings.tsx` shows them on the title screen and the pause menu, with mute (stored in the existing
`GameSettings.muted`, shared with the HUD button), the voices switch and a reset. The engine follows the store
itself; the legacy `setVolumes()` is ignored while a store is active.

Lifecycle: nothing is created before the first user gesture (`unlock()`); `startMusic()` enters the match
soundscape, `stopMusic()` leaves it (ambience fades, generator/engine loops stop), `dispose()` stops everything,
unsubscribes from the preferences and closes the context. All loaders resolve (never reject) and stay silent when
files are missing or fail to decode.

## Adding the founder's audio later

**Music** (`src/audio/music.ts`). List tracks in `public/audio/music/manifest.json`; files go next to it (`.ogg`
preferred, `.mp3` fallback; names `[A-Za-z0-9_-]+`). The player knows six named slots: `menu_loop` (title/menus),
`match_loop` (in-match), `match_tension` (optional stem faded in for the last 30 s, phase-locked to the match loop),
`sting_win`, `sting_lose`, `sting_draw`. Each entry:

```json
{
  "sampleRate": 44100,
  "tracks": {
    "match_loop": { "loop": true, "bpm": 108, "samples": 3136000, "seconds": 71.11,
                    "files": { "ogg": { "file": "match_loop.ogg", "bytes": 1101483 } } }
  }
}
```

`samples` is the exact loop length in frames (it sets `loopEnd`, so MP3 padding cannot break the loop). Only licensed
tracks may be added; record the licence in `public/audio/LICENSES.md`. **Deferred:** rotating a playlist of ten
tracks needs a small extension of `music.ts` (today one track per slot); nothing in the engine or settings blocks it.

**Voices** (`src/audio/pidgin.ts`, triggers in `src/audio/pidginReactions.ts`). Put a recording in
`public/audio/voices/recorded/` and list it in `public/audio/voices/recorded.json` with a licence/consent statement
(required; entries without one are ignored). An `id` from `voices.json` gives that catalogue line a voice; a new
`id` with `category` + `text` adds a line. See `public/audio/voices/recorded/README.md` and the line catalogue in
`docs/VOICE_RECORDING_SCRIPT.md`.

Playback rules (unit-tested): per-category cooldowns of 8-30 s; at least 4.5 s between unforced reaction lines; one
reaction voice at a time; shuffle-bag choice with a 40 s recent-line memory; the previous speaker is avoided;
duplicate triggers within 0.6 s collapse to one; ambient conversations wait 2.5 s after any reaction; beds and music
duck while a line is spoken.

**Ambience and effect overrides** (`src/audio/samples.ts`). Any synthesised sound id (including the beds
`crowd_loop`, `buspark_loop`, `crowd_loop_hype`) can be replaced by a licensed file listed in
`public/audio/slots.json`; see `public/audio/README.md` for the slot table.

## Verification

`tests/audio/`: preferences (defaults, persistence, corruption, clamping), music player (loading, MP3 fallback,
crossfades, loop points, phase-locked stem, stings, silent fallbacks) and voice director (cooldowns, shuffle bag,
variety, dedupe, one voice at a time, ambient scheduling, off switch, recording overrides) against fake servers,
reaction mapping, engine integration, the settings panel, and the rejected-asset guard above. `e2e/audio.spec.ts`
checks in a real browser that no AudioContext exists before the first gesture, that the four sliders persist, and
that no music or voice file is requested. `tools/audio/browserSmoke.mjs` records a bot match through the real engine
in headless Chromium.

Not verified: how anything sounds.
