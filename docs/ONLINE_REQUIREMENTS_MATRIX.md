# City Rumble online: approved requirements against the actual code (branches `claude/wahala-pi-server`, then `claude/wahala-fu2-server`)

Online stays **dormant and development-only**: nothing here enables it in the public build (`tests/online/public-bundle.test.ts`, `scripts/check-static-build.mjs`, `tests/platform-static.test.ts` still pass), nothing is hosted, no endpoint or credential is written anywhere. Decisions: `docs/DECISIONS.md` PIS1-PIS8 (PIS8 is the bot memory leak the soak found: `docs/CITY_RUMBLE_ONLINE.md` section 7.7) and FU2S-1 to FU2S-11 (QUICK PLAY modes, capacity limits, security, reliability: `docs/ONLINE_LIMITS_AND_SECURITY.md`; rows marked **FU2S** below changed). Run the server suite with `cd server && npx vitest run`; the client-side proofs with `npx vitest run tests/online tests/app/rumble-online-flow.test.ts tests/ui/rumble-online-models.test.ts`.

Status: **MET** = the code already did it, now proved by a test; **MISSING-then-FIXED** = a gap was found, fixed (still dormant) and tested; **PARTIAL** = works, with a stated limit that needs a founder decision.
